Entry for the [make.fun bounty "The One-Sentence Apology Your Agent Owes You"](https://make.fun/bounty/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0): a program that writes the single sentence of apology an AI assistant owes the person it works for — funny and human at once.

## The apology

> I'm sorry I confidently finished your sentence, your spreadsheet, and your patience, all in the wrong order.

## Run

```sh
python3 main.py
```

Writes the apology to `out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set) and prints the character count. Deterministic — the same output on every run. Python 3.13, standard library only, no network.
